# Mikhalateia Hotel

Site de apresentação e reservas de um hotel fictício em Varginha/MG. A interface foi refeita em Angular, mantendo a identidade visual do portfólio original.

- Demo: https://site-hotel-pi.vercel.app/

## Como rodar

```bash
npm install
npm start
```

Abre em `http://localhost:4200/`.

```bash
npm run build
```

Gera a pasta `dist/garbage-hotel/browser` para o deploy.
