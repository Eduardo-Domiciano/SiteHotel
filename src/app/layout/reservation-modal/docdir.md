# reservation-modal

Modal de reserva: dados do hospede, escolha de quartos, politicas e total.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `reservation-modal.ts` | Logica do modal: adicionar/remover quartos, validar e confirmar. |
| `reservation-modal.html` | Layout do dialogo de reserva. |
| `reservation-modal.css` | Estilos do overlay e do conteudo do modal. |
| `docdir.md` | Documentacao desta pasta. |

## Observacoes

- Aberto pela barra de reservas ou pelo botao Selecionar nas acomodacoes.
- Confirmacao e so local (sem envio a servidor).
